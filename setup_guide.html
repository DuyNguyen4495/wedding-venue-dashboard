Wedding Venue Dashboard

Running the dashboard on any computer

The dashboard is a self-contained Streamlit app. This is everything needed to run it here, or set it up fresh on another Windows PC or a Mac.

1

What you actually need to copy

Short answer: yes, but only the dashboard folder — not the whole "Wedding Packages" folder. The PDFs, the markdown write-ups, and the two published HTML analyses are separate, standalone documents; the dashboard doesn't read any of them.

FileNeeded?What it's for
app.pyRequiredThe dashboard itself
data/venues.csvRequiredAll the venue data — the app reads this file directly
requirements.txtRequiredTells Python which packages to install
export_excel.pyOptionalOnly needed if you also want the Excel snapshot
README.mdOptionalReference notes on the data schema
💡

Simplest way to move it: right-click the dashboard folder → Compress / Send to → Zip → transfer the single .zip file (email, USB drive, AirDrop, Dropbox/OneDrive, whatever's easiest) → unzip it on the other machine.

2

Run it on this PC

Python and every required package are already installed here. Just open a terminal and run:

# PowerShell
PS> cd "C:\Users\dnguy\Desktop\OMSA\Wedding Packages\dashboard"
PS> streamlit run app.py

It opens automatically at http://localhost:8501. Leave that terminal window open while you use it — closing it shuts the dashboard down.

3

Set up on a new Windows PC or a Mac

a. Install Python, if it isn't already

Download the installer from python.org (version 3.9 or newer). On Windows, check the box that says "Add python.exe to PATH" during install — easy to miss, and everything below depends on it. Macs sometimes have an old system Python preinstalled; installing a current version from python.org avoids version headaches.

b. Copy the dashboard folder onto the new machine

Unzip it wherever's convenient — Desktop is fine. There's no installer step; it's just files.

c. Open a terminal and move into the folder

🪟 Windows — PowerShell
PS> cd "C:\Users\you\Desktop\dashboard"
🍎 Mac — Terminal
$ cd ~/Desktop/dashboard

Quotes around the path only matter if it contains spaces — Mac paths rarely do, Windows ones often do (like the original Wedding Packages folder here).

d. Install the required packages

🪟 Windows
PS> pip install -r requirements.txt
🍎 Mac
$ pip3 install -r requirements.txt

This reads requirements.txt and installs Streamlit, pandas, openpyxl, and Altair — the four packages the app needs. Takes a minute or two on a fresh machine.

e. Run it

🪟 Windows
PS> streamlit run app.py
🍎 Mac
$ streamlit run app.py

Same command on both — Streamlit itself isn't OS-specific. It should open your default browser automatically; if not, the terminal prints a localhost link to open by hand.

4

Keeping data in sync across machines

Each copy of the dashboard folder has its own independent data/venues.csv. If you research new venues on one machine, that file needs to reach the other machine too, or the dashboards will show different data.

  • Simplest: after adding venues on one machine, just copy the updated data/venues.csv file over to the other (same transfer methods as above — it's a small text file, a few KB).
  • Lower-maintenance: put the whole dashboard folder inside a synced cloud folder (OneDrive, Dropbox, iCloud Drive) instead of the Desktop. Both machines then always see the same venues.csv automatically, with no manual copying — just don't run streamlit run app.py from both machines against the same synced folder at the exact same time.
5

Troubleshooting

"python" or "streamlit" isn't recognized as a command

Python isn't on your PATH. Reinstall from python.org and make sure the "Add to PATH" box is checked (Windows), or close and reopen the terminal after installing (both platforms — PATH changes need a fresh terminal window).

cd "Wedding Packages/dashboard" doesn't work

That's a relative path — it only works if your terminal is already sitting inside the OMSA folder. Use the full path instead (see Step 2 above), or run dir (Windows) / ls (Mac) first to confirm what's actually in your current folder.

The browser says the port is already in use

Another Streamlit app (or a previous copy of this one) is already running. Either close that terminal window, or launch this one on a different port: streamlit run app.py --server.port 8502.

Windows Firewall pops up asking for network access

Safe to allow — Streamlit is just serving the page to your own browser on your own machine (localhost), not exposing anything to the internet.

No pins show up on the map

The map only plots venues whose city has a known coordinate in app.py's CITY_COORDS list. A newly added venue in an unlisted city just won't get a pin — it'll still show up fine in every table and filter.

Everything above assumes the same dashboard folder contents documented in README.md — that file has the data schema if you (or Claude) need to add new venues later.
